How to merge PDF files

  1. Select files: choose two or more PDF files.
  2. Arrange: use ◀ ▶ to set the order and ✕ to remove a file.
  3. Merge: click “Merge PDF”, then download the result.

Frequently asked questions

Are my PDF files uploaded?

No. The files are merged inside your browser and never sent to a server.

Can I change the order of the files?

Yes. Use the arrow buttons under each file to move it before you merge.

Why can't some PDFs be merged?

PDFs protected with a password cannot be merged. Remove the password first, then try again.
